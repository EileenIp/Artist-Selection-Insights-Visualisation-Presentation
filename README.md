## Problem Overview


This dataset consists of a million song records as of 2011. The dataset is collected from Million Song Websites.

This project provides an overview of advanced visualisations derived from analysing the million song dataset and offers recommendations.

CLIENT: Gems Event Management – a leading Australian organiser of large-scale music events.

CONTEXT:With growing competition in live entertainment, the client aims to elevate audience engagement, optimise artist/song selection, and maximise concert success. To achieve this, the project visualises and analyses artist popularity, song trends, and technical song features to provide actionable insights for artist selection and event planning.

## Project Summary

This project delivers a visual analysis of artists and songs using a range of metrics:
* Artist Familiarity, Artist Hotness, and Song Hotness
* Song characteristics: Duration, Fade-in/Fade-out, Key, Tempo, Loudness, Mode, and Time Signature
* Release Year


The data visualisations include line plots, bar plots, stacked plots, ridgeline plots, and correlation matrices. These helped:
* Identify top-performing artists and songs
* Determine ideal song characteristics for maximum engagement
* Build a data-driven artist and song recommendation framework

---

## Conclusion

Key insights for artist and song selection:

* Prioritise artists with high familiarity and consistently hot songs

* Optimal artist profile: Familiarity < 60%, Artist hotness < 45%, Song hotness < 50%

* Ideal song features: Duration: 150–225s, Start Fade-out: 150–225s, Fade-in: 0–1s, Loudness: -4dB to -8dB, Tempo: 100–150 BPM, Key: C, D, G, Time Signature: 4/4

These insights support more targeted booking strategies and help align song sets with audience preferences.
